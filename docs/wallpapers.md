# Wallpapers

Native macOS is the 1:1 reference for the desktop's icons, interface, and interaction behavior. The Wallpapers launcher follows the desktop-folder model and belongs on the desktop surface.

The portfolio uses a Mac Stickies-style desktop. Its **Wallpapers** folder floats in the upper-left of the portfolio desktop. Click once to select the folder and double-click to open it. On touch devices, tap once. When the folder has keyboard focus, Enter, Space, Command-O, and Command-Down Arrow open it. Browse thumbnails, choose an image, shuffle on demand, or restore the default background. Shuffle skips the current image. The selected background applies to both desktops and resets on reload.

## Collection

**Wallpapers**, **Files**, and **Archive** share the supplied PNG folder sprite. They move with the portfolio desktop when switching to the idea board. Drag a folder to move it, or focus it and use the arrow keys. Positions last until reload. Files and Archive are empty folders reserved for future use.

The site serves optimized WebP copies from `public/wallpapers`. The collection includes all 12 Banshees of Inisherin images and Miyazaki images 1, 2, 3, and 5. The Miyazaki numbers come from sorting the original image filenames. Entry 4 is `wp4409084.jpg` and entry 6 is `wp9853204.webp`. The original files were kept intact.

## Placement history

The first picker opened from the menu bar. It then moved to the left side of the desktop, where the folder's row shifted the content below it. The folder now uses absolute positioning within the portfolio desktop.
